# Future Roadmap

## Short Term
- Improve dashboard (historical charts, alert log)
- Optimize firmware (memory footprint, loop timing)
- Expand training dataset (more machines, more operating conditions)
- Add confidence-score reporting to inference output

## Mid Term
- Multi-sensor fusion (temperature, current, voltage, RPM)
- OTA (over-the-air) firmware updates
- Better feature extraction (kurtosis, skewness, spectral entropy)
- FreeRTOS-based task scheduling
- Watchdog timer support
- Secure MQTT with TLS

## Long Term
- Remaining Useful Life (RUL) estimation
- Fleet monitoring (multiple machines / multiple ESP32 nodes)
- Cloud synchronization for long-term historical analytics
- Digital twin integration
- Mobile application for remote monitoring
- Automatic model retraining pipeline
