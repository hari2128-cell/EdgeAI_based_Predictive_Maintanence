# Model Artifacts

Stores trained model artifacts generated by the training and conversion pipeline.

| File | Produced By | Purpose |
|---|---|---|
| `model.h5` | `Model_Training/train.py` | Trained Keras model |
| `scaler_stats.npz` | `Model_Training/train.py` | Feature scaler mean/scale + class order |
| `model.tflite` | `TensorFlow_Lite/convert_to_tflite.py` | Quantized TensorFlow Lite model |
| `model_data.h` | `TensorFlow_Lite/convert_to_tflite.py` | C byte array for ESP32 deployment |

**Status:** Empty — no model has been trained yet (no populated dataset). Run the full pipeline (`Feature_Extraction` → `Model_Training` → `TensorFlow_Lite`) after collecting real sensor data in `tinyml/Dataset/`. Until then, `firmware/ESP32/tinyml/model_data.h` contains a placeholder that causes the firmware to fall back to threshold-based classification (see `firmware/ESP32/tinyml/inference.cpp`).
